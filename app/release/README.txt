S2 Dashboard release

This package contains the application and bundled Python runtime only.
The first launch creates a new empty local OWNER account.

User data locations:
- Windows: %LOCALAPPDATA%\S2Dashboard
- macOS: ~/Library/Application Support/S2Dashboard

Production account databases, backups, logs, QA data, and test accounts are
not included. Updating the application must not remove the user-data folder.
